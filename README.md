One hilarious line, 133 characters, that lands entirely on its own: a grandma
joins the family group chat and ends a three-year feud with a single voice note.

> My grandma joined a group chat and ended a three-year family feud with one voice note that just said: 'I can see all of you. Behave.'

## Run it

```sh
python3 main.py
```

It validates the line (one line, at most 200 characters) and writes it to
`entry.txt` inside `MAKEFUN_OUTPUT_DIR`.
